# Weather for City Application

## What is it?

An application which let's you type the city whose weather details you want and then retrieves it's longitude and latitude coordinates from an API request then using those 2 coordinates makes another request to Open_Meteo server API to retrieve those coordinates(city's) weather details

## How to run it?

Just download the repository, and make sure that in your virtual environment you have the requests library installed and then just run either by the play button on your vsc or your preferred python interpreter followed by main.py
